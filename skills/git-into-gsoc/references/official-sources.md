# Official sources

Use these pages for anything that affects a decision: eligibility, dates, which
organizations take part, and how to apply.

| Page | What it answers |
|---|---|
| [GSoC home](https://summerofcode.withgoogle.com) | Announcements, the organization directory, and where proposals are submitted |
| [Timeline](https://developers.google.com/open-source/gsoc/timeline) | Exact dates and times for the current program year |
| [FAQ](https://developers.google.com/open-source/gsoc/faq) | Eligibility, stipends, and how the program works |
| [Resources](https://developers.google.com/open-source/gsoc/resources) | Guides, rules, and contacts |
| [Contributor guide](https://google.github.io/gsocguides/student/) | How to approach a community and write a proposal |
| [Mentor guide](https://google.github.io/gsocguides/mentor/) | How mentors evaluate contributors |
| [AI guidance](https://developers.google.com/open-source/gsoc/resources/ai_guidance) | What the program expects when contributors use AI tools |
| [Proposal quality guidance](https://developers.google.com/open-source/gsoc/resources/spam_proposals) | Why generic or unsupported proposals are rejected |

Each organization adds its own rules: application questions, required
contributions, and an AI policy. Read the organization's current ideas page and
contributor guide before helping with anything the person will submit.

## Where the tool's data comes from

| Data | Source | Notes |
|---|---|---|
| Program timeline | The official site's program data, cached for six hours; an embedded snapshot when offline | Years Google has not published are estimates projected from the previous year |
| Accepted organizations | The official site's accepted-organization list for the latest announced year | Includes ideas page, contributor guide, source code link, and contact channels |
| Organization history and past projects | The community [GSoC Organizations archive](https://api.gsocorganizations.dev/), not a Google service | Years active, projects per year, and accepted project titles since 2016 |
| Repositories and issues | The public GitHub API | Cached for an hour, then revalidated |

If the official site is unreachable, organization results fall back to the
archive copy and the result says so.

## What the data cannot tell you

- Whether an organization will take part next year. Past participation is a lead, not a promise.
- Whether an issue is truly free. The tool reads the issue thread and linked pull requests, but maintainers may coordinate in chat.
- Whether a person will be accepted. Scores rank research leads; they are not odds.
- Whether a date is final. Until Google publishes a year, the tool projects dates from the previous year and marks them as estimates.

When something cannot be verified, say so plainly and point to the official
page.
