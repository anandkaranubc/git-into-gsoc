# Agent notes for this repository

When helping users with Google Summer of Code, load and follow the **git-into-gsoc** skill:

* Canonical: `skills/git-into-gsoc/SKILL.md`
* Project copies (after install): `.agents/skills/git-into-gsoc/`, `.cursor/skills/git-into-gsoc/`, `.claude/skills/git-into-gsoc/`

Prefer live data via CLI/MCP:

```bash
git-into-gsoc program --year 2027
git-into-gsoc orgs --tech … --year 2026
git-into-gsoc repo owner/repo
git-into-gsoc issues --language …
git-into-gsoc mcp
```

Never fabricate organizations, issues, or deadlines. Never encourage spammy AI-generated contributions. Cite official GSoC sources.
