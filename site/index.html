four questions. two minutes.

What you know, what you would enjoy working on, how much time you have, and how much open source you have done. Press Enter to skip any of them. Then you get:

  1. Organizations that fit you, from the official list, each with the reasons it matched and what its ideas page offers.
  2. A shortlist you build by typing numbers, saved in a file on your computer.
  3. Your next steps with the exact commands, so you are never stuck at a blank prompt.

The terminal tool goes further than the browser version: it reads live data to tell you which repositories merge newcomers' work and which beginner issues are still free.

house rules.

These are built into the tool, the assistant skill, and the docs. They are also stickers.

  • Every organization, repository, issue, and date has a source you can open. Scores are explained. When data is missing, the tool says so instead of guessing.

  • No typo farms, no mass "assign me" comments, no generated essays. One useful change you understand well enough to defend in review is worth more than twenty you don't.

  • The tool never posts, comments, or submits anything for you. Your profile and progress stay in a file on your computer. No account, no tracking. Every message a maintainer reads is one you wrote.

  • The goal is a reviewed, merged contribution and a mentor who knows your name from useful work.

The assistant setup guide covers manual configuration, and the MCP reference lists every tool.

Or add only the server to one app with one click. All but the Claude Desktop download need uv, a free tool that runs it. The app shows what it will run and asks you first:
