the door, drawn.

This is how git into gsoc looks and sounds. Every asset here is generated from one pixel grid by a script in the repository, so the identity is open source too. Use it to write about the project, build on it, or print a sticker. Just don't make it look official.

Download everything from brand/

SVG first. PNG, ICO, and a WOFF2 font are included for the places that need them.

the idea.

The name is a pun on "get into", and the mark takes it literally.

The G is a doorway. Its opening, the gap every G has on the right, is the door. The small block at the threshold is a terminal cursor: the thing that blinks at you when the machine is waiting for you to type. In this identity the cursor is always the person. The G is the community they are stepping into, and it works for both Git and GSoC without borrowing either logo.

The cursor is the one thing allowed to move. On the website and in the README banner it blinks at one beat per second, the way a prompt does. Everything else stays still.

Both the mark and the typeface are drawn on a square grid with a thick stroke, so they stay sharp at 16 pixels and feel like one object at 16 feet. The grid is the retro-tech note. The lowercase voice and the violet keep it from reading as nostalgia.

logo.

Pick by background, not by taste. On light surfaces the cursor is ink; on dark surfaces it is lime. The tile works anywhere and is the avatar.

Do

  • Keep clear space of one cursor width (3 grid units) around the mark.
  • Use the tile below 48 px. Use the bare mark at 48 px and up.
  • Scale in whole multiples where you can; the grid stays crisp.
  • Let the cursor blink, and only the cursor. Respect reduced-motion settings.
  • Say "git into gsoc" in lowercase in running text, and git-into-gsoc for the command.

Don't

  • Recolour the G outside the three schemes, or add gradients, outlines, or shadows.
  • Rotate it, skew it, or set it in a circle other than GitHub's avatar crop.
  • Replace the cursor with an emoji, a dot, an arrow, or a Git branch icon.
  • Place it next to the Google or Google Summer of Code logos, or in their colours.
  • Rebuild the wordmark in another typeface. It is not a font setting; it is a drawing.

colour.

Violet is the colour of a merged pull request, which is the point of all this. Lime is the cursor and nothing else. Both have deeper siblings for body text so every pairing clears WCAG AA.

type.

Two families. Gig Pixel is ours: a lowercase pixel face on a two-cell stroke, drawn on the same grid as the mark and built into a real font by the same script. It carries headlines and stickers. Instrument Sans carries everything you have to read for more than a line. Code is the system monospace.

Gig Pixel rules

  • Lowercase only. Uppercase letters map to the lowercase drawings, so shouting is impossible.
  • Use it at 32, 48, 64, 80, or 96 px. A cell is one sixteenth of an em, so those sizes land on whole pixels.
  • Headlines, section titles, stickers, and the one-line tagline. Never body copy, never below 32 px.
  • Files: GigPixel.woff2, GigPixel.ttf, specimen.svg. MIT licensed like the rest.

Instrument Sans rules

  • Body at 17 px with 1.55 line height, lines under 70 characters.
  • Weights 400 for text, 500 for navigation, 600 for subheadings. No 700 unless it's a button.
  • Sentence case. No all-caps labels, no letterspaced eyebrows.
  • Loaded from Google Fonts with a system-ui fallback, so the page still reads if the request fails.

voice.

Lowercase, dry, warm. The brand talks like a good mentor in a chat window: short sentences, specific nouns, no hype.

Sounds like us

  • open source has a door. git in.
  • evidence > vibes.
  • contested. pick another issue, or offer to review the open PR.
  • missing data is reported as missing.
  • one real contribution before applications open.

Doesn't

  • 🚀 Unlock your GSoC journey today!!!
  • The ultimate AI-powered toolkit for 10x contributors.
  • Guaranteed acceptance strategies.
  • Anything that implies Google built or endorsed this.
  • Slang used because it is slang. If a mentor wouldn't say it, cut it.
