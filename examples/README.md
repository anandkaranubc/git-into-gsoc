# Examples

Working examples to copy from. Run the terminal examples from the repository folder after installing, with the environment turned on:

```bash
source .venv/bin/activate
```

| File | What it shows |
|---|---|
| [cli-session.sh](cli-session.sh) | A complete terminal session, from checking your setup to a proposal checklist. It only reads public data: nothing is posted to GitHub and nothing is saved locally. Run it with `bash examples/cli-session.sh` |
| [assistant-prompts.md](assistant-prompts.md) | Prompts to paste into an AI assistant that has the skill or the MCP server connected |
| [mcp.cursor.json](mcp.cursor.json) | A sample MCP server entry for Cursor. Replace the placeholder path before using it |

The [beginner guide](../docs/README.md) explains each step in detail, and the [command reference](../docs/cli.md) lists every option.
