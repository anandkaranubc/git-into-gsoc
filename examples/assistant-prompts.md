# Assistant prompts

## Start the journey

```
Load the git-into-gsoc skill. I'm preparing for GSoC 2027.
I know Python and JavaScript, can spend ~15 hours/week, and care about developer tools.
Walk me through the learn and discover phases with evidence.
```

## Evaluate a repo

```
Using git-into-gsoc, evaluate microsoft/vscode-python for first-time contribution fitness.
Summarize grade, warnings, and whether I should pick something smaller.
```

## Find an issue ethically

```
Find available beginner-friendly issues in Python scientific orgs that participated in GSoC 2026.
Do not suggest claimed or stale issues. For the top pick, tell me what to read before commenting.
```

## Proposal critique

```
Critique my draft GSoC proposal against the git-into-gsoc proposal checklist and official spam/AI guidance.
Flag generic AI phrasing. Do not rewrite it in a different voice—give concrete edits.
```
