# Your path to a first contribution

You do not need to understand the whole project on day one. Work through one step at a time. If you already know a topic, skip to the next step.

| Step | What you will leave with |
|---|---|
| [1. Understand GSoC](guide/01-understand-gsoc.md) | The basics, official rules, and a realistic starting goal |
| [2. Install the tool](guide/02-install.md) | A working command and a way to check your setup |
| [3. Connect your AI assistant (optional)](guide/03-connect-your-ai-assistant.md) | An assistant that can use the same tools |
| [4. Find organizations](guide/04-find-organizations.md) | A short list of communities you want to learn about |
| [5. Pick a repository and an issue](guide/05-choose-an-issue.md) | One task you understand and can investigate |
| [6. Make your first contribution](guide/06-first-contribution.md) | A change ready for review and a clear explanation of it |
| [7. Prepare your proposal](guide/07-prepare-a-proposal.md) | A plan based on real project work and feedback |
| [8. Keep track of your progress](guide/08-track-progress.md) | Notes and a manageable next step |

Join a community and keep notes whenever they become useful. These steps are a guide, not a required sequence or an acceptance checklist.

## Lost? Ask the tool

Once you have [installed it](guide/02-install.md), `git-into-gsoc start` asks four quick questions and suggests organizations that fit you. Run `git-into-gsoc` on its own any time to see your progress. `git-into-gsoc next` reads the program calendar, your saved profile, and your progress, re-checks the issues you track, and prints the next few actions with the exact commands. Use it whenever you are not sure what to do.

## Just trying the tool?

Start with [installation](guide/02-install.md), run `git-into-gsoc start`, then [find organizations](guide/04-find-organizations.md). The command-line interface, or **CLI**, means you type a command in a terminal and read its response. You can complete the journey without an AI assistant.
